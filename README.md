🛡️ SurakshaAI

AI Powered Financial Fraud Detection System
SurakshaAI is an AI-powered web application designed to detect fraudulent SMS, Emails, and WhatsApp messages. It helps users identify potential financial scams by combining Machine Learning, keyword analysis, suspicious URL detection, and risk assessment into one simple and user-friendly platform.

🚀 Features

- 🤖 AI-based Scam Detection
- 📊 Risk Score Meter
- 🎯 AI Confidence Indicator
- 🧠 Explainable AI (Reason Detection)
- 🛡 Personalized Safety Tips
- 📜 Scan History
- 📈 Statistics Dashboard
- 🌙 Dark Mode Support
- 📄 Professional PDF Report Generation
- 📱 Fully Responsive Design
- 🎨 Modern User Interface

🚀 How to Run

Clone Repository
git clone https://github.com/Meghapatel2005/SurakshaAI.git

Go to Project Folder
cd SurakshaAI

Install Dependencies
pip install -r requirements.txt

Start Backend
uvicorn main:app --reload

Open Frontend
Open "frontend/index.html" in your browser.
